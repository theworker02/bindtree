# bindtree

Bind digests and tree fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/bindtree/

## Install / run

```bash
git clone https://github.com/theworker02/bindtree.git
cd bindtree
node src/cli.js
node --test
```
